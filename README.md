## 🛠️ Projects

### 📄 [Doclivo](https://github.com/Nishanthmalladi/Doclivo): free file converter + PDF editor
🌐 **Live:** [doclivo.onrender.com](https://doclivo.onrender.com)

A free website that converts files between formats and lets you edit PDFs, with no sign-up and no watermarks.

- 🔄 Converts Word, PowerPoint, Excel, PDF and images in almost any direction
- 📦 Handles **up to 15 files at once** in a single batch
- ✂️ PDF tools: merge, split, compress, reorder, page numbers, password, edit
- 💧 Removes watermarks from PDFs and Word files
- 🗑️ Files are deleted automatically after converting

**Tech:** Python · FastAPI · LibreOffice · PyMuPDF · pdf.js · JavaScript · Docker · Render
